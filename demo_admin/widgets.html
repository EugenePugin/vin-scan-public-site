Управление веб-виджетами

Веб-виджет представляет из себя интерактивный чат во всплывающем окне, который можно разместить на страницах Вашего сайта. Такой чат может подбирать запчасти для посетителей, и далее перенаправлять их на страницу уточнения цен и покупки запчастей на Вашем сайте. Все диалоги и сообщения, созданные через виджеты, автоматически помещаются в папку «Widget-диалоги» на странице чата.

Безопасность и доступ

Ограничьте использование виджета выбранными сайтами

Укажите адрес каждого сайта с новой строки, например https://example.com. Виджет будет принимать вызовы только с перечисленных сайтов, вызовы с остальных сайтов будут блокироваться. Указывайте основной адрес без пути к отдельной странице. Если оставить поле пустым, виджет не будет работать ни на одном сайте.

Продвижение Вашей компании

Чат-виджет в диалогах с пользователями будет рекомендовать и всячески продвигать Вашу компанию. Также после проценки товаров в таблице результатов мы будем показывать ссылки на страницу поиска (проценки) товаров на Вашем сайте, используя найденные артикулы. Обратите внимание: данная настройка является глобальной для Вашего аккаунта и действует и для веб-чата, и для API-вызовов, и для виджетов. Изменить эту настройку можно в разделе «Чат», в окне редактирования учётной записи.

Лимиты и расходы

Ограничьте сложность запросов, длину контекста и бюджет выбранного виджета.

Сколько запчастей можно подобрать в рамках одного текстового запроса через чат. Группы запчастей и комплекты ТО автоматически разворачиваются в списке запчастей перед поиском. Выберите значение от 1 до 20. Рекомендованное значение 10.

Сколько предыдущих сообщений в диалоге надо учитывать при обработке нового сообщения от пользователя. Чем больше предыдущих сообщений нужно учитывать, тем дороже будет обработка. Выберите значение от 0 до 100. Рекомендованное значение 20.

Минимальная вероятность соответствия запчасти запросу и автомобилю пользователя. Все найденные запчасти с меньшей вероятностью не будут показаны в результатах поиска. Выберите значение от 0 до 100. Рекомендованное значение 65.

Суммарный дневной лимит расходов для данного виджета. Виджет работает по модели тарификации, аналогичной веб-чату. За каждое обработанное сообщение взимается плата, в зависимости от сложности и длины сообщения. Рекомендованное значение 1000.

Суммарный месячный лимит расходов для данного виджета. Виджет работает по модели тарификации, аналогичной веб-чату. За каждое обработанное сообщение взимается плата, в зависимости от сложности и длины сообщения. Рекомендованное значение 9000.

Применяется к посетителю с externalUserId. Значение -1 означает «без персонального лимита», 0 полностью запрещает обращения, положительное число задаёт лимит в рублях.

Применяется к посетителю без externalUserId. Значение -1 означает «без персонального лимита», 0 полностью запрещает обращения, положительное число задаёт лимит в рублях.

ИИ-модули и инструкции

Определите доступные сценарии обработки запросов посетителей.

У нас есть два режима поиска: быстрый и глубокий. Быстрый поиск рекомендуется для большинства запросов. Глубокий режим предназначен для редких сложных случаев и расходует больше средств. В 90% случаев быстрый поиск хорошо справляется с задачами, при этом стоит на 40–50% дешевле.

Активные субагенты

Выберите активных суб-агентов внутри виджета. Если некоторый модуль отключён, виджет не сможет маршрутизировать к нему новые запросы посетителей.

Расскажите о компании, правилах общения, ассортименте и важных ссылках. Напишите пожелания по стилю общения, который ИИ-чатбот должен соблюдать.

Расширенная стилизация

Необязательные CSS-правила для элементов виджета, встроенных в страницу сайта.

Используйте только при необходимости. Ограничивайте каждый селектор корневым классом .vinscan-widget-root, чтобы правила не затронули страницу клиента.
